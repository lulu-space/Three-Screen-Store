# Three Screen Store

A Flutter e-commerce app featuring product browsing, detailed product pages, and a checkout flow. Built with multi-language support (English & Arabic) and a clean, responsive Material Design UI.

## Screens

- **Splash Screen** — Animated intro that transitions to the home screen
- **Home Screen** — Browse products by category with a responsive product grid
- **Product Details** — Full product info with add-to-cart action
- **Checkout** — Order form with city picker and delivery details
- **Success Screen** — Order confirmation after checkout

## Features

- 🌐 Bilingual support (English & Arabic) with RTL layout
- 🎨 Material Design 3 theming
- 🗺️ Named route navigation
- 📦 Clean project structure with separate models, screens, widgets, and data layers

## Getting Started

```bash
flutter pub get
flutter run
```
